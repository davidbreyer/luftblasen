Tic Tac Words

Reveal the hidden board with five-letter tests. Answer squares earn X moves.

Puzzle

Mode Tic-Tac Logic
Guesses 0 / 6
X Marks 0 / 3
O Blocks 0
  1. The 3x3 board starts hidden.
  2. Enter any five letters. It does not need to be a word.
  3. Green reveals answer squares and unlocks X moves.
  4. Blue reveals decoys. Gray letters are not on the board.
  5. If no answer square unlocks, O blocks a dangerous square.
